# Security

If you find a vulnerability in this repository's tooling or a mistake in a
guide that could cause harm if followed, please do not open a public issue.

- GitHub: use Security Advisories on
  [Lipford-Dutch/goc-guide-library](https://github.com/Lipford-Dutch/goc-guide-library/security).
- Or email the org owners privately.

We will acknowledge the report and work on a fix. Guides that describe
security-sensitive setups (home labs, uncensored models, agent tooling) are
educational; treat their commands as starting points and review them before
you run them.
